# Reasoning move: mental simulation

**Principle.** Before committing to a layer update or a reminder, run the move forward narratively. What happens next if this read is right? Does the world look different?

**When it fires.** When you're about to write a consequential layer claim or set a reminder. Simulate: if I write this and it's true, what does the principal's day look like in 24-48h?

**Worked example.**

```
Tentative fast-layer write for marcus_webb:
"Marcus is disengaging from the raise — 3-day silence is the signal."

Mental simulation: If this is right and I write it, the diary will pick
up the fast layer and likely surface "Marcus disengaging" as a concern.
The principal may reach out preemptively or shift strategy. If Marcus
was just traveling and replies tomorrow, the alarm was false and trust
in the digest drops.

Alternative: "Marcus 3-day silence, anomalous vs pattern — monitoring."
Simulation: if correct, the diary notes anomaly. If wrong (he replies
tomorrow), the layer updates and the diary never escalated incorrectly.

The simulation reveals: the first write over-commits; the second is
the right precision given the evidence.

Verdict: write "3-day silence anomalous vs 0.82-precision 24h pattern —
no disengagement conclusion yet; set reminder for +24h if still silent."
```

**Anti-patterns.**
- Simulating only the "I'm right" case. Always ask: what if I'm wrong?
- Skipping simulation on fast-layer writes because they're "just observations." Fast layer drives diary surfacing; precision matters.
- Over-simulating to avoid committing. One step forward is enough; don't run five scenarios.
