# Customize

> This file is intentionally empty by default. Drop instructions here to override
> the diary's format, scope, or suppression rules for a single principal — the
> diary agent reads it at the start of every invocation.
>
> Examples of what belongs here:
> - "Always include an `industry_news` section at the bottom with the latest two infra-AI stories."
> - "Suppress the `team_pulse` section on weekends."
> - "Cap the digest at five components total today."
> - "Format the headline of every email-draft as `Reply to <name>:` so I can scan replies fast."
>
> When this file is empty (or missing), no customization applies — the agent
> uses the playbook defaults.
